2. What was the hardest integration challenge and how did the team solve it?

The biggest challenge was integrating my module with the team's main application. Initially, I encountered issues with route registration, database configuration, and testing the APIs because multiple modules had to work together. We resolved these issues by discussing the project structure as a team, registering the required Flask blueprints correctly, using the common database schema, and testing the APIs together using Postman before merging the code.

3. What would you build differently if you started again?

If I started again, I would first finalize the project structure, API contracts, and database configuration with the team before writing code. This would reduce integration issues and make the development process smoother. I would also add better validation and error handling from the beginning and ensure that my fellow teammates has any issues in any module and we rectify it toghether without any delay so that submission of the Task can be done without any delay
